GUI Package — Графический интерфейс приложения "Роботы"
Пакет gui реализует графический интерфейс пользователя (GUI) для приложения управления роботами.

Основные возможности:

-Управление несколькими роботами (максимум 2)
-Визуализация движения роботов к заданным целям
-Отображение лога событий
-Просмотр координат роботов в реальном времени
-Сохранение/восстановление положения окон при перезапуске
-Управление с клавиатуры (цифры 1, 2 для выбора робота)

gui/
├── MainApplicationFrame.java      # Главное окно приложения 
├── GameWindow.java                # Окно игрового поля
├── GameVisualizer.java            # Компонент отрисовки роботов и целей
├── LogWindow.java                 # Окно протокола работы (лог)
├── RobotCoordinatesWindow.java    # Окно с координатами роботов
├── RussianLocalizer.java          # Локализация интерфейса на русский язык
└── RobotsProgram.java             # Точка входа в приложение

1. RobotsProgram.java — Точка входа

public class RobotsProgram {
    public static void main(String[] args)
}

Основные задачи:

-Применение русской локализации через RussianLocalizer
-Создание и отображение главного окна MainApplicationFrame

Ключевые моменты:

-Использует SwingUtilities.invokeLater() для потокобезопасного запуска GUI
-Устанавливает режим MAXIMIZED_BOTH для главного окна

2. MainApplicationFrame.java — Главное окно
   Назначение: MDI-контейнер, управляющий всеми внутренними окнами.

MainApplicationFrame (JFrame)
└── JDesktopPane
    ├── LogWindow
    ├── GameWindow
    └── RobotCoordinatesWindow

Основные функции:

Создание и расположение внутренних окон
Создание меню (Файл, Режим отображения, Тесты)
Сохранение/восстановление позиций окон в XML-файл (~/.robots_window_config.xml)
Обработка выхода из приложения

3. GameWindow.java — Окно игрового поля
   Назначение: Контейнер для визуализации игрового процесса.

GameWindow (JInternalFrame)
    └── JPanel (BorderLayout)
        └── GameVisualizer (CENTER)

Особенности:

Заголовок: "Игровое поле"
Все кнопки управления: закрыть, свернуть, развернуть, изменить размер
Всплывающая подсказка с инструкцией

4. GameVisualizer.java — Визуализатор игрового поля
   Назначение: Отрисовка роботов, целей, обработка пользовательского ввода.

Отрисовка:

Робот: Вытянутый овал (30x10) с "глазом" для определения направления
Цель: Зелёный кружок (10x10) с крестиком внутри
Выбранный робот: Подсветка жёлтым полупрозрачным кругом
HUD: Подсказки внизу экрана

5. LogWindow.java — Окно протокола
   Назначение: Отображение лога событий приложения.

Оптимизации:

Хэширование содержимого (lastHash) для предотвращения лишних обновлений
Флаг needsUpdate для дедупликации событий
Обновление через SwingUtilities.invokeLater()

Паттерн Observer:
LogWindow подписывается на LogWindowSource
При добавлении сообщения вызывается onLogChanged()
Обновление UI происходит асинхронно

6. RobotCoordinatesWindow.java — Окно координат
   Назначение: Отображение текущих координат и параметров роботов.

Отображаемая информация для каждого робота:
Позиция X (с одним знаком после запятой)
Позиция Y
Направление (в градусах)
Цель X
Цель Y

Особенности:
Автоматическое обновление при изменении параметров
Динамическое добавление/удаление панелей при изменении количества роботов
GridBagLayout для аккуратного расположения

7. RussianLocalizer.java — Локализация
   Назначение: Установка русскоязычного интерфейса для Swing-компонентов.

Что локализуется:
Диалоги подтверждения (Да/Нет/Отмена/OK)
Диалоги выбора файлов
Кнопки заголовков внутренних окон (Закрыть, Свернуть, Развернуть, Восстановить)
Системное меню внутренних окон



Оптимизации
Двойная буферизация (setDoubleBuffered(true)) — устранение мерцания
Разделение частоты — модель 60 FPS, отрисовка 30 FPS
Флаг needsRepaint — накопление изменений перед отрисовкой
Хэширование контента — в LogWindow для предотвращения лишних обновлений
Флаг needsUpdate — дедупликация событий в LogWindow
CopyOnWriteArrayList — потокобезопасное хранение роботов

Известные ограничения
Максимум 2 робота
Переключение роботов только по клавишам 1 и 2
Нет масштабирования игрового поля
Лог хранит только последние 100 сообщений (настройка в LogWindowSource)
